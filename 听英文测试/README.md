# 听英文测试 · 单词速答限时测验（分享版）

一个纯前端、可离线分发的单词听力速答工具。学生打开网页即听单词发音，并在限定时间内作答。

## 功能
- **自动朗读**：浏览器直连 Microsoft Edge 神经语音（与 Azure 同款录音棚级音色，美/英/澳口音、男/女声可选），免密钥、免服务器。
- **限时答题**：每题可选 1/2/3/4/5/6/7/8/10 秒或不计时。
- **两种答题方式**（进入测试前自选，测试中锁定）：
  - 文字输入：键盘打字，Enter 提交。
  - 语音输入：单词播完自动聆听，识别到答案后自动提交。
- **本地存档**：错题、成绩保存在浏览器 localStorage，可导出。

## 使用
直接用 Chrome / Edge 打开 `index.html` 即可。若某浏览器/网络拦截 Edge 直连，会自动降级为系统语音，题目照常可答。

## 部署
本目录随 GenuineEdu 主站一同发布于 GitHub Pages：
`https://AprilPlatanus.github.io/GenuineEdu/听英文测试/`

如需 100% 保真 Edge 音质，可在设置中填写「自定义 TTS 代理地址」（将本机 `server.py` 经隧道公开后的地址）。
